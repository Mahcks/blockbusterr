## Filter System

Filters are applied **before** scoring. Content that fails filters is immediately rejected.

### Global vs Per-Job Filters

<Tabs>
<TabItem label="Global Filters" icon="star">

Apply to **all jobs** across the board:

```yaml
filters:
  global:
    blocking:
      certifications:
        - "R"
        - "NC-17"
      genres:
        - "horror"
    required:
      min_runtime: 90
```

**Use for:** Consistent rules across all content (e.g., family-friendly server)

</TabItem>
<TabItem label="Per-Job Filters" icon="puzzle">

Override global filters for specific jobs:

```yaml
jobs:
  family_movies:
    filters:
      required:
        certifications: ["G", "PG", "PG-13"]
      blocking:
        genres: ["horror", "thriller"]
  
  adults_only_night:
    filters:
      required:
        certifications: ["R"]
      min_rating: 7.0
```

**Use for:** Job-specific requirements that differ from global rules

</TabItem>
<TabItem label="Combining Filters" icon="setting">

Job filters **override** global filters for matching keys:

```yaml
filters:
  global:
    required:
      min_runtime: 90  # Global: 90min minimum

jobs:
  short_films:
    filters:
      required:
        max_runtime: 60  # This job: override to 60min max
```

<Aside type="note">
Non-conflicting filters are combined. Conflicting ones are replaced by job-specific values.
</Aside>

</TabItem>
</Tabs>

### Available Filters

<Tabs>
<TabItem label="Certifications" icon="approve-check">

Control content ratings (movie ratings, TV ratings).

**Required certifications** (only allow these):

```yaml
filters:
  movies:
    required:
      certifications: ["G", "PG", "PG-13"]
  
  shows:
    required:
      certifications: ["TV-Y", "TV-G", "TV-PG"]
```

**Blocked certifications** (reject these):

```yaml
filters:
  global:
    blocking:
      certifications:
        - "NC-17"
        - "TV-MA"
```

**Movie Certifications:**
- `G` - General Audiences
- `PG` - Parental Guidance
- `PG-13` - Parents Strongly Cautioned
- `R` - Restricted
- `NC-17` - Adults Only

**TV Certifications:**
- `TV-Y` - All Children
- `TV-Y7` - Children 7+
- `TV-G` - General Audience
- `TV-PG` - Parental Guidance
- `TV-14` - Parents Strongly Cautioned
- `TV-MA` - Mature Audience

</TabItem>
<TabItem label="Genres" icon="star">

Control content by genre.

**Required genres** (must have at least one):

```yaml
filters:
  movies:
    required:
      genres:
        - "science-fiction"
        - "fantasy"
```

**Blocked genres** (reject if has any):

```yaml
filters:
  global:
    blocking:
      genres:
        - "horror"
        - "documentary"
        - "reality"
```

**Common genres:**
- Movies: `action`, `adventure`, `comedy`, `drama`, `science-fiction`, `fantasy`, `thriller`, `horror`, `romance`, `documentary`
- TV: `drama`, `comedy`, `reality`, `animation`, `documentary`, `talk-show`, `game-show`

<Aside type="tip">
Use lowercase with hyphens: `science-fiction` not `Science Fiction`
</Aside>

</TabItem>
<TabItem label="Runtime" icon="rocket">

Control content length (in minutes).

```yaml
filters:
  movies:
    required:
      min_runtime: 90      # Feature films
      max_runtime: 180     # Under 3 hours
  
  shows:
    required:
      min_episode_runtime: 20   # No shorts
      max_episode_runtime: 60   # Standard episodes
```

**Common use cases:**
- Feature films only: `min_runtime: 90`
- No epics: `max_runtime: 150`
- Standard TV: `min_episode_runtime: 20, max_episode_runtime: 60`
- Anime episodes: `min_episode_runtime: 22, max_episode_runtime: 25`

</TabItem>
<TabItem label="Release Year" icon="laptop">

Control how old/new content can be.

```yaml
filters:
  required:
    min_year: 2020       # Only 2020 onwards
    max_year: 2024       # Nothing from 2025+
```

**Use cases:**
- Modern only: `min_year: 2015`
- Classics: `max_year: 1999`
- Current year: `min_year: 2026, max_year: 2026`

</TabItem>
<TabItem label="Languages & Countries" icon="translate">

Control content origin.

```yaml
filters:
  required:
    languages: ["en"]                # English only
    countries: ["us", "gb", "ca"]    # US, UK, Canada
```

**Blocking:**

```yaml
filters:
  blocking:
    languages: ["ja", "ko"]          # No Japanese or Korean
    countries: ["cn"]                # No Chinese productions
```

**Common language codes:**
- `en` - English
- `es` - Spanish
- `fr` - French
- `de` - German
- `ja` - Japanese
- `ko` - Korean
- `zh` - Chinese

</TabItem>
<TabItem label="Networks" icon="television">

Control TV networks (shows only).

```yaml
filters:
  shows:
    required:
      networks:
        - "HBO"
        - "Netflix"
        - "Apple TV+"
```

**Blocking networks:**

```yaml
filters:
  shows:
    blocking:
      networks:
        - "Adult Swim"
        - "MTV"
```

</TabItem>
</Tabs>

## Scoring System

<Badge text="0-100 Scale" variant="success" />

Content that passes filters is scored from 0-100 based on weighted ratings.

### Score Components

<Tabs>
<TabItem label="Rating Sources" icon="star">

Four rating sources can be weighted:

```yaml
scoring:
  imdb_rating_weight: 0.4      # IMDb rating (40%)
  trakt_rating_weight: 0.3     # Trakt rating (30%)
  tmdb_rating_weight: 0.2      # TMDB rating (20%)
  metacritic_weight: 0.1       # Metacritic (10%)
```

**Weights must sum to 1.0**

<Aside type="note">
If a source is unavailable (e.g., no Metacritic score), the other weights are proportionally increased.
</Aside>

</TabItem>
<TabItem label="Vote Requirements" icon="approve-check">

Require minimum votes for reliable ratings:

```yaml
scoring:
  min_imdb_votes: 5000      # At least 5,000 votes
  min_trakt_votes: 100      # At least 100 votes
```

**Without minimum votes**, content with few votes can have inflated ratings.

**Example:**
- Movie A: 9.5 rating (10 votes) ❌ Rejected
- Movie B: 8.2 rating (50,000 votes) ✅ Accepted

</TabItem>
<TabItem label="Release Recency" icon="rocket">

Set minimum release year:

```yaml
scoring:
  min_year: 1990     # No content before 1990
```

**Different from filters:** This is scoring-based, not a hard block.

</TabItem>
<TabItem label="Default Score" icon="setting">

Fallback score when ratings unavailable:

```yaml
scoring:
  default_score: 50     # Middle ground
```

**Use cases:**
- New releases without ratings yet
- Content from sources without rating data
- Unreleased anticipated content

</TabItem>
</Tabs>

### Threshold Score

<Badge text="Job-Specific" variant="tip" />

Each job has a `threshold_score` - only content scoring above this is added.

```yaml
jobs:
  quality_movies:
    threshold_score: 75    # Only scores 75+ added
  
  everything_movies:
    threshold_score: 50    # More permissive
```

**Typical thresholds:**
- Very Strict: 80-90
- Quality Focus: 70-79
- Balanced: 60-69
- Permissive: 50-59
- Very Permissive: &lt;50

## Configuration Examples

<Tabs>
<TabItem label="Family Server" icon="star">

**Goal:** Kid-safe content only.

```yaml
scoring:
  imdb_rating_weight: 0.6
  trakt_rating_weight: 0.4
  min_imdb_votes: 1000
  default_score: 50

filters:
  global:
    blocking:
      certifications:
        - "R"
        - "NC-17"
        - "TV-MA"
        - "TV-14"
      genres:
        - "horror"
        - "thriller"
    required:
      certifications:
        - "G"
        - "PG"
        - "PG-13"
        - "TV-Y"
        - "TV-G"
        - "TV-PG"

jobs:
  family_movies:
    threshold_score: 65
```

</TabItem>
<TabItem label="Quality Curator" icon="approve-check">

**Goal:** Only highly-rated, proven content.

```yaml
scoring:
  imdb_rating_weight: 0.4
  trakt_rating_weight: 0.3
  tmdb_rating_weight: 0.2
  metacritic_weight: 0.1
  min_imdb_votes: 50000      # Require popularity
  min_year: 1990

filters:
  movies:
    required:
      min_runtime: 90
    blocking:
      genres:
        - "documentary"
        - "reality"

jobs:
  curated_movies:
    threshold_score: 80      # Very high bar
```

</TabItem>
<TabItem label="Genre Specialist" icon="heart">

**Goal:** Sci-fi and fantasy only.

```yaml
scoring:
  imdb_rating_weight: 0.5
  trakt_rating_weight: 0.5
  min_imdb_votes: 5000

filters:
  global:
    required:
      genres:
        - "science-fiction"
        - "fantasy"
    blocking:
      genres:
        - "romance"      # No romantic fantasy
        - "comedy"       # Serious only

jobs:
  scifi_movies:
    threshold_score: 70
```

</TabItem>
<TabItem label="Current Releases" icon="rocket">

**Goal:** Latest theatrical and streaming releases.

```yaml
scoring:
  imdb_rating_weight: 0.3
  trakt_rating_weight: 0.4
  tmdb_rating_weight: 0.3
  min_imdb_votes: 500        # Lower for new releases
  min_year: 2024             # Current year only
  default_score: 60          # Give new content a chance

filters:
  movies:
    required:
      min_year: 2024
      min_runtime: 75

jobs:
  new_releases:
    threshold_score: 60      # Medium bar for new content
```

</TabItem>
</Tabs>

## Testing Filters

<Aside type="tip" title="Always Preview First">
Use the preview feature to see what passes your filters before enabling jobs.
</Aside>

<Tabs>
<TabItem label="Web UI" icon="laptop">

<Steps>

1. Configure filters in the **Config** page
2. Go to **Jobs** page
3. Configure a test job
4. Click **Preview**
5. Review results:
   - ✅ Items that pass (will be added)
   - ❌ Items filtered out (with reasons)
   - 📊 Score distribution
6. Adjust filters based on results

</Steps>

</TabItem>
<TabItem label="API" icon="rocket">

```bash
curl -X POST http://localhost:9090/api/v1/jobs/preview/trending-movies
```

**Response shows:**

```json
{
  "would_add": [...],
  "filtered_out": [
    {
      "title": "Horror Movie",
      "reason": "Blocked genre: horror"
    },
    {
      "title": "Low-Rated Film",
      "score": 45,
      "reason": "Score below threshold (65)"
    }
  ]
}
```

</TabItem>
</Tabs>

## Best Practices

<Steps>

1. **Start strict, then loosen**
   
   Begin with high thresholds and tight filters, then relax as needed.

2. **Use previews extensively**
   
   Always preview before enabling jobs to avoid surprises.

3. **Combine filters and scoring**
   
   Use filters for hard requirements, scoring for quality ranking.

4. **Monitor the activity log**
   
   Check weekly to see what's being added and adjust.

5. **Set realistic vote minimums**
   
   For new content: 500-1000 votes. For established: 5000-10000 votes.

6. **Don't over-filter**
   
   Too many filters = nothing gets added. Find the right balance.

</Steps>

## Troubleshooting

<Aside type="caution" title="Nothing Being Added?">

**Common issues:**

1. **Threshold too high** - Try lowering to 60-65
2. **Filters too strict** - Remove some blocking filters
3. **Vote requirement too high** - Lower min_votes for new content
4. **Already in library** - Check activity log

**Debug steps:**

```bash
# Preview job to see what's being filtered
curl -X POST http://localhost:9090/api/v1/jobs/preview/trending-movies

# Check logs
docker logs blockbusterr | grep filtered
```

</Aside>
