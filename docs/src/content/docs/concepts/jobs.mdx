## Dynamic Job System

<Badge text="New in v1.4.0" variant="success" />

Create custom jobs with full control over type, media, limits, and settings - all from the UI.

### Creating Jobs

<Tabs>
<TabItem label="From Template" icon="star">

<Steps>

1. Navigate to **Jobs** page
2. Click **Add Job**
3. Select **Movies** or **TV Shows** tab
4. Click a template card (e.g., "Trending Movies")
5. Job is created with sensible defaults
6. Click the job card to customize settings

</Steps>

</TabItem>
<TabItem label="Custom Job" icon="setting">

<Steps>

1. Navigate to **Jobs** page
2. Click **Add Job**
3. Select **Custom** tab
4. Fill in:
   - **Name** - Descriptive name for your job
   - **Type** - trending, popular, watched, etc.
   - **Media** - Movies or Shows
   - **Limit** - How many items to fetch (up to 1000)
   - **Period** - Required for watched/collected/favorited/played
5. Click **Create Job**
6. Configure advanced settings as needed

</Steps>

</TabItem>
</Tabs>

### Content Limits

<Aside type="tip">
Jobs can fetch up to **1000 items** per run when supported by the selected job type and provider.
</Aside>

| Job Type | Default | Maximum |
|----------|---------|---------|
| Trending | 50 | 1000 |
| Popular | 50 | 1000 |
| Watched/Collected/etc. | 50 | 1000 |
| Box Office | 10 | 10 |
| Smart Popular | 50 | 1000 |

### Migrating Legacy Jobs

If you have jobs configured in your `config.yaml`, a migration banner appears on the Jobs page.

<Steps>

1. Click **Migrate Jobs** in the banner
2. Legacy jobs are converted to dynamic format
3. All settings (schedule, limits, filters) are preserved
4. Legacy config remains as backup (no longer used)

</Steps>

<Aside type="note">
Migration is optional. Legacy jobs continue to work - you can migrate when ready.
</Aside>

## Job Configuration

<Tabs>
<TabItem label="Legacy Format" icon="pencil">

Jobs defined directly in config (pre-v1.4.0):

```yaml
jobs:
  sync_interval: "6h"     # Default interval for all jobs
  mode: "direct"          # direct or jellyseerr

  trending_movies:
    enabled: true
    limit: 20
    sync_interval: "6h"   # Override default
    mode: "direct"
    minimum_availability: "released"
    monitor: "movieOnly"

  popular_shows:
    enabled: true
    limit: 30
    monitor: "all"
```

</TabItem>
<TabItem label="Dynamic Format" icon="setting">

Dynamic jobs (v1.4.0+) - defined in `jobs.list`:

```yaml
jobs:
  sync_interval: "6h"
  mode: "direct"

  list:
    - id: "my-trending-movies"
      name: "My Trending Movies"
      enabled: true
      type: "trending"
      source: "trakt"
      media: "movie"
      limit: 50
      sync_interval: "6h"
      mode: "direct"
      minimum_availability: "released"
      monitor: "movieOnly"

    - id: "weekly-watched"
      name: "Weekly Most Watched"
      enabled: true
      type: "watched"
      source: "trakt"
      media: "movie"
      limit: 30
      period: "weekly"
```

</TabItem>
<TabItem label="Smart Job" icon="rocket">

Smart job with adaptive thresholds:

```yaml
jobs:
  list:
    - id: "smart-movies"
      name: "Smart Popular Movies"
      enabled: true
      type: "smart_popular"
      source: "trakt"
      media: "movie"
      limit: 50
      base_min_rating: 6.0       # Base rating threshold
      adjustment_factor: 0.5     # Popularity adjustment (0.1-1.0)
```

See [Smart Jobs](/concepts/smart-jobs/) for details.

</TabItem>
</Tabs>

### Configuration Options

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `id` | string | No | Unique identifier (auto-generated if omitted) |
| `name` | string | Yes | Display name for the job |
| `enabled` | boolean | Yes | Enable or disable the job |
| `type` | string | Yes | Job type: `trending`, `popular`, `watched`, `collected`, `favorited`, `played`, `anticipated`, `box_office`, `smart_popular` |
| `media` | string | Yes | `"movie"` or `"show"` |
| `limit` | integer | No | Max items to fetch (defaults to job type default) |
| `period` | string | No | Time period for watched/collected/favorited/played: `weekly`, `monthly`, `yearly`, `all` |
| `sync_interval` | string | No | Custom sync interval (e.g., `6h`, `12h`, `24h`) |
| `mode` | string | No | Override global mode: `direct` or `jellyseerr` |
| `minimum_availability` | string | No | For Radarr: `announced`, `in_cinemas`, `released` |
| `monitor` | string | No | Monitor setting for Radarr/Sonarr |
| `base_min_rating` | float | No | Smart jobs: base rating threshold |
| `adjustment_factor` | float | No | Smart jobs: popularity adjustment |

## Scheduling

Jobs run on a configurable interval using duration strings.

<Tabs>
<TabItem label="Interval Format" icon="document">

The `sync_interval` field uses Go duration format:

| Value | Meaning |
|-------|---------|
| `1h` | Every hour |
| `6h` | Every 6 hours |
| `12h` | Every 12 hours |
| `24h` | Once per day |
| `168h` | Once per week (7 days) |

</TabItem>
<TabItem label="Recommended Intervals" icon="star">

| Job Type | Recommended Interval | Reason |
|----------|---------------------|--------|
| Trending | `6h` | Changes frequently |
| Popular | `12h` - `24h` | Updates daily |
| Watched/Collected/etc. | `24h` | Aggregated data, slower updates |
| Box Office | `24h` - `168h` | Weekly data |
| Anticipated | `24h` | Upcoming releases |
| Smart Popular | `12h` - `24h` | Adaptive filtering |

</TabItem>
<TabItem label="Best Practices" icon="approve-check">

**Use different intervals per job:**

```yaml
jobs:
  list:
    - id: "trending-movies"
      name: "Trending Movies"
      type: "trending"
      media: "movie"
      sync_interval: "6h"    # Check frequently
      # ...

    - id: "popular-movies"
      name: "Popular Movies"
      type: "popular"
      media: "movie"
      sync_interval: "12h"   # Less frequent
      # ...

    - id: "weekly-watched"
      name: "Weekly Watched"
      type: "watched"
      media: "movie"
      period: "weekly"
      sync_interval: "24h"   # Once per day
      # ...
```

<Aside type="tip">
Jobs with longer intervals reduce API calls and server load while still catching new content.
</Aside>

</TabItem>
</Tabs>

## Job Workflow

<Steps>

1. **Fetch from the discovery provider**

   The job contacts its selected provider and retrieves the chosen list up to the configured `limit`.

2. **Apply Filters**

   Content is filtered based on your global filter criteria (ratings, genres, countries, languages, runtime, etc.)

3. **Fetch Metadata**

   Retrieve TMDB metadata for poster images and additional details

4. **Check Existing**

   Skip content already in Radarr/Sonarr or Jellyseerr

5. **Add Content**

   Send to Radarr/Sonarr (direct mode) or create Jellyseerr request

6. **Log Activity**

   Record what was added/filtered in the activity log

</Steps>

## Preview Jobs

<Aside type="tip" title="Always Preview First">
Use the preview feature to see what will be added **before** enabling a job.
</Aside>

<Tabs>
<TabItem label="Web UI" icon="laptop">

<Steps>

3. Click **Preview** button
4. Review the results:

   - ⚠️ Items filtered out (with reasons)
   - ℹ️ Items already in library
5. Adjust filters/scoring as needed
6. Enable when satisfied

## Example Configurations

<Tabs>
<TabItem label="Balanced" icon="approve-check">

**Goal:** Good mix of current and quality content.

```yaml
jobs:
  sync_interval: "6h"
  mode: "direct"

  list:
    - id: "trending-movies"
      name: "Trending Movies"
      enabled: true
      type: "trending"
      media: "movie"
      limit: 50
      sync_interval: "6h"

    - id: "smart-popular-movies"
      name: "Smart Popular Movies"
      enabled: true
      type: "smart_popular"
      media: "movie"
      limit: 30
      sync_interval: "12h"
      base_min_rating: 6.5
      adjustment_factor: 0.5

    - id: "favorited-movies"
      name: "Favorited Movies"
      enabled: true
      type: "favorited"
      media: "movie"
      limit: 20
      period: "weekly"
      sync_interval: "24h"
```

**Result:** ~10-15 movies/week, mix of current and quality

</TabItem>
<TabItem label="Quality Focus" icon="star">

**Goal:** Only the best content with smart filtering.

```yaml
jobs:
  list:
    - id: "smart-movies"
      name: "Smart Popular Movies"
      enabled: true
      type: "smart_popular"
      media: "movie"
      limit: 100
      sync_interval: "24h"

      type: "favorited"
      media: "movie"
      limit: 50
      period: "all"
      sync_interval: "168h"    # Weekly
```

**Result:** ~5-8 excellent movies/week

</TabItem>

## Troubleshooting

<Aside type="caution" title="No Content Being Added?">
Common issues:
- Global filters too strict (check min_rating, min_votes in filters section)
- Content already in library (check activity log)
- Job not enabled (verify `enabled: true`)
- Selected discovery provider is not configured
- Period required but not set (for watched/collected/favorited/played jobs)
</Aside>
