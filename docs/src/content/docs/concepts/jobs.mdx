## Job Configuration

<Tabs>
<TabItem label="Basic" icon="pencil">

Minimal configuration to get started:

```yaml
jobs:
  trending_movies:
    type: "movie"
    list_type: "trakt_trending"
    enabled: true
    schedule: "0 */6 * * *"  # Every 6 hours
    fetch_count: 20
    threshold_score: 65
```

</TabItem>
<TabItem label="Advanced" icon="setting">

Full configuration with filters and scoring:

```yaml
jobs:
  curated_popular:
    type: "movie"
    list_type: "trakt_popular"
    enabled: true
    schedule: "0 0 * * *"    # Daily at midnight
    fetch_count: 100          # Fetch 100 items
    threshold_score: 70       # Score must be 70+
    
    # Optional: Override global filters for this job
    filters:
      min_runtime: 90
      max_runtime: 180
      exclude_genres:
        - "documentary"
    
    # Optional: Override global scoring for this job
    scoring:
      imdb_rating_weight: 0.5
      trakt_rating_weight: 0.5
```

</TabItem>
<TabItem label="Smart Job" icon="rocket">

Smart job with adaptive thresholds:

```yaml
jobs:
  smart_popular_movies:
    type: "movie"
    list_type: "smart_trakt_popular"
    enabled: true
    schedule: "0 6 * * *"     # Daily at 6 AM
    fetch_count: 50
    threshold_score: 70       # Base threshold
    
    # Smart-specific settings
    base_min_rating: 7.0      # Baseline rating requirement
    adjustment_factor: 2.0    # How aggressive (0.5-3.0)
```

See [Smart Jobs](/blockbusterr/concepts/smart-jobs/) for details.

</TabItem>
</Tabs>

### Configuration Options

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `type` | string | Yes | `"movie"` or `"show"` |
| `list_type` | string | Yes | Which Trakt list to use |
| `enabled` | boolean | Yes | Enable or disable the job |
| `schedule` | string | Yes | Cron schedule |
| `fetch_count` | integer | Yes | Max items to fetch from Trakt |
| `threshold_score` | integer | Yes | Minimum score (0-100) to add |
| `filters` | object | No | Override global filters |
| `scoring` | object | No | Override global scoring weights |

## Scheduling

<Tabs>
<TabItem label="Cron Syntax" icon="document">

Jobs use standard cron syntax:

```
┌───────────── minute (0 - 59)
│ ┌───────────── hour (0 - 23)
│ │ ┌───────────── day of month (1 - 31)
│ │ │ ┌───────────── month (1 - 12)
│ │ │ │ ┌───────────── day of week (0 - 6, Sunday = 0)
│ │ │ │ │
* * * * *
```

</TabItem>
<TabItem label="Common Patterns" icon="star">

| Pattern | Description | Use Case |
|---------|-------------|----------|
| `"0 */6 * * *"` | Every 6 hours | Trending content |
| `"0 0 * * *"` | Daily at midnight | Popular/favorited |
| `"0 12 * * 1"` | Monday at noon | Weekly updates |
| `"*/30 * * * *"` | Every 30 minutes | Aggressive (not recommended) |
| `"0 0 1 * *"` | 1st of month | Monthly collections |
| `"0 6,18 * * *"` | 6 AM and 6 PM | Twice daily |

</TabItem>
<TabItem label="Best Practices" icon="approve-check">

**Stagger your schedules:**

```yaml
trending_movies:
  schedule: "0 0 * * *"    # Midnight

popular_movies:
  schedule: "0 6 * * *"    # 6 AM

anticipated_movies:
  schedule: "0 12 * * *"   # Noon

favorited_shows:
  schedule: "0 18 * * *"   # 6 PM
```

<Aside type="tip">
Don't run all jobs at once - spread them throughout the day to avoid API rate limits and server load.
</Aside>

</TabItem>
</Tabs>

## Job Workflow

<Steps>

1. **Fetch from Trakt**
   
   Job contacts Trakt API and retrieves the specified list (trending, popular, etc.)

2. **Apply Filters**
   
   Content is filtered based on your criteria (ratings, genres, certifications, etc.)

3. **Fetch Metadata**
   
   Retrieve IMDb/TMDB ratings and additional metadata for scoring

4. **Calculate Scores**
   
   Weighted scoring algorithm calculates a 0-100 score for each item

5. **Check Threshold**
   
   Only items meeting `threshold_score` proceed

6. **Check Existing**
   
   Skip content already in Radarr/Sonarr or Jellyseerr

7. **Add Content**
   
   Send to Radarr/Sonarr (direct mode) or create Jellyseerr request

8. **Log Activity**
   
   Record what was added/rejected in the activity log

</Steps>

## Preview Jobs

<Aside type="tip" title="Always Preview First">
Use the preview feature to see what will be added **before** enabling a job.
</Aside>

<Tabs>
<TabItem label="Web UI" icon="laptop">

<Steps>

1. Navigate to **Jobs** page
2. Configure your job settings
3. Click **Preview** button
4. Review the results:
   - ✅ Items that will be added
   - ⚠️ Items filtered out (with reasons)
   - ℹ️ Items already in library
5. Adjust filters/scoring as needed
6. Enable when satisfied

</Steps>

## Example Configurations

<Tabs>
<TabItem label="Balanced" icon="approve-check">

**Goal:** Good mix of current and quality content.

```yaml
jobs:
  trending_movies:
    type: "movie"
    list_type: "trakt_trending"
    enabled: true
    schedule: "0 */6 * * *"
    fetch_count: 50
    threshold_score: 65
  
  smart_popular_movies:
    type: "movie"
    list_type: "smart_trakt_popular"
    enabled: true
    schedule: "0 0 * * *"
    fetch_count: 30
    threshold_score: 70
  
  favorited_movies:
    type: "movie"
    list_type: "trakt_favorited"
    enabled: true
    schedule: "0 12 * * 0"  # Weekly

    threshold_score: 75
```

**Result:** ~10-15 movies/week, mix of current and quality

## Troubleshooting

<Aside type="caution" title="No Content Being Added?">
Common issues:
- Threshold score too high (try lowering to 60-65)
- Filters too strict (check min_rating, min_votes)
- Content already in library (check activity log)
- Job not enabled (verify `enabled: true`)
- Schedule not running (check cron syntax)
</Aside>
