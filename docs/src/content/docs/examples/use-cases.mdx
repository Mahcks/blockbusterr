title: Use Cases
description: Practical v2 job and rule-set arrangements for common media libraries.

## One simple discovery job

Create a TMDB Trending Movies job, assign **Default Movies**, preview it, and enable it. This is enough to run Blockbusterr; additional providers are optional.

## Family and personal libraries

Create two movie rule sets:

- **Family Movies:** allowed languages, family-friendly genres, recent-year boundary, and blocked title exceptions.
- **Personal Movies:** broader genres and a higher minimum rating.

Assign each set to the jobs feeding its intended library or approval workflow.

## Provider diversity with one policy

Create TMDB Trending, Simkl Trending, and Trakt Anticipated jobs, then assign the same **Current Releases** rule set to all three. Editing that rule set updates every assigned job while each provider continues discovering independently.

## A special-purpose job

Start with a shared **Default Movies** assignment, open one job, and choose **Make job-specific copy**. Add required science-fiction genres or keywords to the new copy without changing any other job.

## Approval-first automation

Set the default delivery mode to Jellyseerr, assign conservative rules, and run a preview. Accepted titles become Jellyseerr or Seerr requests; approval and forwarding remain controlled by that service's user permissions.

## Fully automated library loop

Use Blockbusterr to discover and add suitable content, then use Maintainerr independently to remove or unmonitor stale and unwatched content. Coordinate Blockbusterr title exceptions and Maintainerr cleanup rules so removed titles are not repeatedly rediscovered.

## Tuning workflow

1. Preview the job.
2. Inspect the accepted and rejected distribution.
3. Open decision details for unexpected titles.
4. Adjust the assigned rule set or add a universal title exception.
5. Preview again before enabling delivery.

After enabling, use **Job Runs** for aggregate health and **Activity Entries** for title-level explanations.
