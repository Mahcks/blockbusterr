## Your media discovery layer

Blockbusterr sits between discovery providers and delivery applications:

`TMDB / Simkl / Trakt → Blockbusterr → Radarr / Sonarr / Jellyseerr / Seerr`

It does not replace your request manager, `*arr` applications, download client, or media server. It automates the decision about what should enter that workflow.

## One provider is enough

Configure TMDB, Simkl, or Trakt, then create a supported job using that source. Multiple providers improve coverage but are not required.

Accepted movies can go directly to Radarr and accepted shows to Sonarr, or both can become Jellyseerr or Seerr requests for an approval-first workflow.
