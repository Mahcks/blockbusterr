## Quick Example

```yaml
jobs:
  trending_movies:
    enabled: true
    sync_interval: "6h"
    limit: 20

filters:
  movies:
    min_rating: 6.5
    min_votes: 1000
    blacklisted_genres: ["documentary"]
```

This configuration checks trending movies every six hours and applies the global movie filters to every movie job.

## Features at a Glance

- **Automated Job Scheduling**: Set up recurring jobs to fetch content
- **Preview Mode**: See what will be added before committing
- **Filter System**: Min/max ratings, votes, runtime, genres, keywords
- **Scoring Engine**: Rank content by multiple weighted factors
- **Web UI**: Manage configuration and view activity from your browser
- **REST API**: Integrate with other tools
- **Docker Ready**: Single container deployment
