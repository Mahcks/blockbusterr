# Blockbusterr product context

## Register

Product. The interface serves repeatable self-hosted media operations.

## Users

- Self-hosted media operators configuring automated discovery.
- Curators running multiple discovery strategies.
- Maintainers diagnosing automation through Activity Entries and Job Runs.
- Open-source contributors extending and supporting the project.

## Purpose

Blockbusterr automatically discovers movies and shows from Trakt, TMDB, and Simkl, evaluates them against understandable rules, then sends approved content to Radarr, Sonarr, Jellyseerr, or Seerr. One discovery source is enough to operate; multiple sources improve coverage.

## Product personality

Restrained, operational, and dependable. The interface keeps Activity's dark visual language, compact navigation, sharp hierarchy, minimal cards, local assets, and no decorative dashboard filler.

## Primary tasks

1. Confirm configuration and integration health.
2. Create jobs and preview their results before enabling automation.
3. Apply filters and reusable policies to discovery strategies.
4. Understand outcomes through Activity Entries and Job Runs.

## Strategic principles

- Put outcomes before configuration.
- Preview before consequence.
- Explain every automated decision.
- Reveal advanced controls progressively.
- Remain one small self-hosted container.

## Accessibility

Support keyboard navigation, visible focus, reduced motion, color-independent status, and responsive end-to-end workflows.

## Anti-references

Avoid generic AI SaaS dashboards, decorative hero or KPI grids, glass effects, gradients, excessive pills and cards, decorative motion, and comments that narrate obvious code.
