About Jobs

Jobs automatically fetch content from Trakt and add them to Radarr/Sonarr based on the sync interval. You can edit settings for each job individually and test them using "Run Now". Existing content is automatically detected and skipped to avoid duplicates. {{if eq .Version "dev"}}⚠️ Running in DEV mode - jobs will run in dry-run (no content will be added).{{end}}
